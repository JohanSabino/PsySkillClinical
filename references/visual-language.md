# Lenguaje visual y accesibilidad

## Mapas iniciales

1. **Hexaflex contextual:** seis procesos alrededor de patrones y recursos; los procesos no son una escala.
2. **Ciclo funcional:** contexto → experiencia/conducta → efecto corto/largo plazo → dirección valiosa. Las flechas inferidas llevan “hipótesis”.
3. **Brújula valores–acciones:** valores confirmados, barreras, apoyos y pasos pequeños.
4. **Hoja de ruta de sesiones:** sesiones como tarjetas con foco, decisión, práctica y criterio de adaptación.

Usa formas y etiquetas además del color: dato, hipótesis, objetivo, barrera, recurso, intervención y acción acordada deben distinguirse en texto. Evita flechas gruesas que sugieran causalidad y medidores que parezcan puntuaciones clínicas.

## Entrega

El HTML debe ser un solo archivo offline con texto equivalente, títulos semánticos, foco visible, botones con etiquetas, contraste suficiente y soporte de `prefers-reduced-motion`. La vista paciente nunca se deriva por ocultamiento visual: se proyecta desde una allowlist validada.
